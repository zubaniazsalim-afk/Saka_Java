# Vehicle Management System

## Project Overview
This project demonstrates Object-Oriented Programming principles such as
inheritance, abstraction, composition, and aggregation using a Vehicle
Management System.

## Class Hierarchy
- Vehicle (abstract superclass)
- Car, Motorcycle, Truck (subclasses)
  Each subclass overrides engine methods to provide specific behavior.

## Access Modifiers
- private: encapsulation of data
- protected: shared access for subclasses

## Compile and Run
javac *.java
java Main

## Reflection
Inheritance simplified the system by allowing common behavior to be reused.
Method overriding allowed each vehicle to have customized engine behavior.
Working with protected access required careful design to avoid misuse.
